# RENASOUND releases

Installers for RENASOUND, the DAW. The app's **Update** button (next to Audio setup) downloads new versions from here.

Current version: **0.10.1** (build 11). Download the installer for your computer from the list of files above:

- **Mac:** download `RENASOUND-macOS.dmg`, open it and drag RENASOUND into Applications. The first time, right-click RENASOUND, choose Open, then Open again (the app isn't signed with an Apple developer certificate yet).
- **Windows:** download `RENASOUND-Windows.zip`, unzip it and run `RENASOUND.exe` (if SmartScreen warns, choose More info, then Run anyway).
